# Participant Guide

Welcome! This repository is designed for a beginner-friendly debugging event.

## How to participate

1. Read the challenge issue and open the source file linked in it.
2. Run the program using the sample input from the issue.
3. Compare the actual output with the expected output.
4. Investigate the relevant loop, condition, or boundary case.
5. Make a minimal fix and test it with the sample plus at least one additional case.
6. Follow the event organiser's instructions for submitting your solution.

## Ground rules

- Do not change the intended task or the input/output format.
- Do not post complete fixes or spoilers in public issue comments while the event is running.
- Keep changes focused on the challenge you are solving.
- Explain what behaviour was wrong and how your change corrects it.
- Be respectful when asking questions or reviewing another participant's work.

## Local setup

For C, install GCC or another C compiler and run, for example:

```bash
gcc C/01-sum-of-numbers.c -o challenge
./challenge
```

For Python, use Python 3:

```bash
python3 Python/01-number-guessing.py
```

Have fun and happy debugging!
